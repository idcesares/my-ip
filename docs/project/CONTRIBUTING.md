# Contributing

1. Create a feature branch.
2. Keep TypeScript strict and lint clean.
3. Add/adjust tests for behavioral changes.
4. Run: `npm run typecheck && npm run lint && npm run test:coverage && npm run build && npm run test:smoke && npm run format`.
5. For metric changes, document whether the value is direct, estimated, unsupported, unavailable, or user-triggered.
6. Open a PR with clear scope and desktop/mobile screenshots for UI changes.
